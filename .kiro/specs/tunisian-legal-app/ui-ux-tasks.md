## Design Principles
- **Cultural Authenticity**: All designs must reflect authentic Tunisian culture
- **Accessibility First**: Every UI element must be accessible and inclusive
- **Performance Optimized**: All animations and interactions must be smooth and responsive
- **Multi-language Ready**: All designs must work perfectly in Arabic (RTL), French, and English
- **Real Data Integration**: All UI components work with live data, no mock data creation
- **Mobile First**: Prioritize mobile experience while ensuring web compatibility
